# Verification: sharing and export

Use only disposable sessions/references because this checklist creates unauthenticated bearer links and downloads files. Use two recipient browser profiles with no account, at least two vaults containing anchored notes on one personal reference, a screen reader, denied clipboard permission, and Save as PDF. Revoke every created link after the pass.
