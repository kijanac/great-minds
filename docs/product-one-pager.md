# Great Minds: a research assistant that thinks from your sources

Great Minds is a tool for turning a serious body of source material into a living research partner. Instead of asking an AI to answer from general training data or from a pile of loosely searched documents, a user builds a project around primary sources, articles, notes, transcripts, or other materials. Great Minds reads them closely, extracts source-grounded ideas, organizes those ideas into a synthesized wiki, and then lets users ask questions, test interpretations, and produce new educational or ideological materials with the original evidence always close at hand.

The central promise is simple: the AI should not float above the texts. It should think with them.

## The Problem It Solves

Researchers, educators, and organizers already turn to LLMs for help thinking through complex bodies of material. The problem is that a general-purpose LLM starts blank each time. The user has to keep re-explaining the sources, the political or theoretical frame, the vocabulary, the history, the standards of evidence, and the kind of answer they are trying to produce. That makes the work slower, less rigorous, and easy to derail.

Most AI tools can summarize a file or retrieve a passage, but they are not built to carry a whole research context forward. They blur source evidence with their own assumptions, treat each question as a one-off chat, and force the user to do the same setup work over and over. Useful answers disappear into a transcript instead of becoming part of the shared context for future work.

Great Minds is designed for the workflow people are already trying to create with LLMs, but in a more streamlined and rigorous form: the relevant source base, interpretive frame, prior synthesis, and evidence trails are already there when the user starts asking questions.

## How It Works

Users create a project, add source materials, and optionally give the project an editorial focus: for example, whether the system should prefer historical events, political debates, movements, concepts, or other kinds of framing. The system then compiles the source base in stages.

First, it preserves the raw materials and indexes them so every source remains readable and searchable. Then it extracts structured "idea cards" from each document: what the document is about, key people or concepts, claims the document makes, and the exact quotes that support those claims. From there, Great Minds groups ideas across the whole collection and creates a canonical topic registry: a structured map of the worldview, themes, and relationships emerging from the source base. Finally, it writes a browsable wiki, with citations back to the raw materials.

The result is both an explorable knowledge layer and an AI assistant that can query it. The user can browse the wiki, inspect source documents, search the original corpus, follow links between topics, and ask natural-language questions. When the assistant answers, it shows the searches, sources, articles, passages, and connections it used, so users can evaluate the answer instead of simply trusting it.

## What Users Can Do With It

Great Minds supports research as a conversation, not just as retrieval. A user can ask a broad question, follow up on a specific claim, highlight a passage and start a quick "BTW" side thread, or spin that side thread into a full research session. Sessions are saved automatically and can be exported as markdown or PDF, making them reusable work products rather than disposable chats.

It also supports compounding knowledge. If an answer or exchange becomes useful, it can be saved back into the project as a new source. User corrections, disagreements, added context, and source deletion requests can enter a review flow rather than remaining comments on the side. Once approved and recompiled, those contributions become part of the same knowledge pipeline as the original materials.

This makes the tool useful for:

- exploring a line of thought across a large source base;
- checking whether an interpretation is actually supported by the texts;
- understanding the history, politics, and internal debates of a corpus;
- applying an existing worldview to new situations while keeping the analysis accountable to its sources;
- producing articles, study guides, explainers, curricula, scripts, briefs, and other educational materials;
- maintaining a shared organizational knowledge base with roles, review, and source governance.

## Why It Is Different

Great Minds is not only a chatbot over files. It is a system for building a structured, source-grounded intellectual layer on top of a corpus.

The wiki gives users a stable map of the materials. The query interface gives them a thought partner that can move between synthesis and raw evidence. The BTW feature makes marginal questions and close-reading side paths natural. Saved sessions and promoted exchanges let knowledge compound. The review and proposal system supports collaborative curation. The API and API keys make it possible to build other tools on top: custom teaching apps, publishing workflows, research dashboards, or domain-specific assistants that call into the same grounded knowledge base.

For a non-technical user, the value is that Great Minds helps transform a scattered archive into an active intellectual resource. It lets people read more deeply, ask better questions, trace ideas back to evidence, preserve the results of their thinking, and turn research into new knowledge products without losing contact with the original texts.
